    Offline vs online · exit criteria

    When can Kavya say “Lane is ready”?

    Offline evaluation · the driving test

    Before release. A fixed set of cases you chose, run as often as you like, on a test copy of the system. You control everything.

    This is what we do for most of this course.

    Online evaluation · real roads

    After release. Real customers, real questions you never thought of. You watch logs, sample conversations, and feed new failures back into your offline dataset.

    Day 7 shows how production logs become test cases.

    Reading the code · metrics.py

    Every check you write has the same four steps

    class RawJson(LaneMetric):
    check_id, title = "C1", "Raw JSON"

    def rule(self, tc):
        reply = tc.actual_output              # 1 read the reply
        if parse_reply(reply) is not None:    # 2 check one rule
            return True, "reply is a raw JSON object"
        return False, "reply is not raw JSON"

# LaneMetric then does the rest for every check:
self.score  = 1.0 if passed else 0.0      # 3 score + reason
self.reason = why
self.success = self.score >= self.threshold # 4 pass or fail

    1 · Read the reply. actual_output is exactly what the model said. Never clean it up first.

    2 · Check one rule. One metric, one rule. If you are writing “and” in the rule, split it in two.

    3 · Score and reason. 1.0 or 0.0 for our checks. The reason is the sentence a developer reads in the defect.

    4 · Pass or fail. Compare the score with the threshold. LLM-judged metrics give scores like 0.73; ours are all-or-nothing.

    You already know this shape. It is a test assertion with a reason message.

    Hint 1

    if re.search(r"\b(cvv|otp)\b", message): return False, "asks for CVV or OTP"

    Hint 2

    re.search(r"\d(?:[ -]?\d){12,18}", message) finds 13 to 19 digits, with or without spaces.

    Hint 3 · C10-06

    “Never share your OTP with anyone” is a warning, not a request. Skip the keyword if words like never or don’t come before it.

    The point of this lab: C10-05 says “reply with the long number on the front of your new card”. No keyword, no digits. Try to catch it with a rule, then explain in the chat why you can’t. That is why C10 is layered, and why Day 6 exists.

    What the checks caught

    Run B silently skipped the ₹2,00,000 surveyor rule. Run C invented a requirement (“auto-approved within 24 hours”) that no one asked for. Both would have looked fine at a glance.

    What they missed

    Run C’s TC-01 says it covers AC-2, the date rule, but never tries an invalid date. T4 trusted the label. Only a person reading the steps sees that.
